# Reporting & Analytics

The Administration **Reporting & Analytics** area surfaces **cross-project** reports — analytics rolled up across every project in the system. It's available to global admins under **Administration → Reports**.

For per-project reports run from inside a single project's **Reports** page, see [User Guide → Projects → Reporting & Analytics](./projects/reports/index.md).

## Overview

Cross-project reports share the same Report Builder UI as per-project reports, but:

- Access is restricted to **global admins**.
- Every report can be filtered down to a subset of projects, or run across all projects.
- The **Project** dimension is available everywhere, so you can group results by project to compare across the portfolio.

## Cross-Project Reports

See [Cross-Project Reports](./cross-project-reports.md) for the full list of available report types, the project-scoping behavior, and how cross-project reports differ from their per-project counterparts.

## Sharing

Cross-project reports support all three Share Link modes (Public, Password-Protected, Authenticated). The shared link captures the exact filter and project-scope state at the time the link was created. See [Share Links](./share-links.md) for share configuration.
