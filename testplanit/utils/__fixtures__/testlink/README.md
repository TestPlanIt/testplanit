# TestLink export fixtures

Both files were written for these tests, in the structure TestLink's export
code produces.

- `handwritten-project.xml` is a whole-project export: an unnamed root suite,
  nested suites, steps, keywords, custom fields, platforms, requirements,
  embedded attachments, a relation and an inactive case.
- `handwritten-testcases.xml` is the export of one suite's test cases, with a
  case in the layout TestLink used before version 1.9.
