# TestRail export fixtures

- `xray-comic-estore.xml` is an unmodified TestRail suite export from
  [Xray-App/xray-code-snippets](https://github.com/Xray-App/xray-code-snippets)
  (`use_cases/import_from_testrail/cloud/comic_estore.xml`), Copyright (c) 2021
  Xray App, BSD-3-Clause. Its licence is in `xray-comic-estore.LICENSE.txt`.
- `handwritten-suite.xml` was written for these tests in the same structure. It
  covers what the Xray file lacks: escaped HTML bodies, section names containing
  path separators, estimates, references and nested custom fields.
